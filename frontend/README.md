# Causelab interface

Next.js / React / TypeScript frontend for the Causelab reliability prototype.

```sh
npm ci
npm run dev
```

Open `/demo`. The recorded demo needs no backend, account, or model key. `/about` explains the project and limitations; `/demo/compare` shows the fixed benchmark across versions.

For local live mode copy `.env.example` to `.env.local`, set `ENABLE_LIVE_UI=true`, and run the backend described in the root README. All public deployments should leave this switch disabled.

`npm run lint`, `npm run typecheck`, `npm run build`, and `npm run test:e2e` validate the interface. Install Chromium with `npx playwright install --with-deps chromium` in a supported Linux environment. `npm run record` captures a silent walkthrough against a running server on port 3000.

Recorded fixture JSON is generated by `../scripts/build_demo.py`; shared view DTOs live in `src/lib/contracts.ts`. Do not edit generated fixture JSON manually.
